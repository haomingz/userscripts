# userscripts

个人使用的 Tampermonkey（油猴）脚本集合。

| 脚本 | 用途 | 文档 |
| --- | --- | --- |
| [Plex 中文番剧 MAL 匹配助手](./plex/Plex%20Chinese%20MAL%20Helper.user.js) | 将 Plex 中文番剧匹配到 MAL，提供候选、手动关联和 MAL-Sync 标题辅助 | [中文安装与使用说明](./plex/README.md) |
| [Orpheus & Redacted: YAETS](./red/Yet%20Another%20External%20Tracker%20Searcher.user.js) | 音乐站点外部搜索 | 脚本内说明 |
| [GGn Mobygames Uploady](./ggn/GGn%20Mobygames%20Uploady.user.js) | GGn 上传页面的 MobyGames 资料辅助 | 脚本内说明 |

安装时打开所需 `.user.js` 文件，复制完整内容到 Tampermonkey 的新建脚本中并保存。站点权限、配置和使用限制请参阅各脚本文档。
